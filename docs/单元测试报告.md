## 4. 已覆盖的边界场景

- 订单事务回滚：多商品中一件库存不足时，已扣库存回滚
- 地址归属校验：使用他人地址下单失败且库存不变
- 订单号冲突：重复订单号重试成功与重试耗尽失败
- 订单快照防腐：地址变更/商品改价后历史订单不被污染
- 取消订单约束：仅 `pending/paid` 可取消，取消后回滚库存
- JWT 安全边界：过期 token、非法 token、AT/RT claim 校验
- Schema 边界：用户名/密码长度、密码复杂度、手机号格式、订单数量合法性
- AI 规则边界：预算解析（`k/千/万`）、文本相似度空值、向量损坏降级
- 前端 store 边界：购物车去重、数量归零移除、认证状态判断
- 请求工具边界：`AbortController` 手动取消、取消错误识别
