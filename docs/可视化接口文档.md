更新时间：2026-03-25

## 5. 关键时序图

### 5.1 登录 + 无感刷新

```mermaid
sequenceDiagram
    participant FE as Frontend
    participant API as /api/auth/*
    participant DB as SQLite

    FE->>API: POST /auth/login
    API->>DB: 校验用户 + 写 refresh_token 哈希
    API-->>FE: access_token + HttpOnly refresh_token

    FE->>API: 业务请求（携带 AT）
    API-->>FE: 401（AT 过期）
    FE->>API: POST /auth/refresh（Cookie 带 RT）
    API->>DB: 校验 RT 哈希/有效期
    API-->>FE: new access_token
    FE->>API: 重放原请求
    API-->>FE: 200
```

### 5.2 AI SSE 流式协议

```mermaid
sequenceDiagram
    participant FE as fetchSSE
    participant API as POST /api/ai/chat/stream
    participant LLM as Chat Completion

    FE->>API: content + context
    API->>LLM: 构建 messages（含业务快照）
    loop 流式输出
        API-->>FE: data: {"type":"delta","content":"..."}
    end
    API-->>FE: data: {"type":"cards","cards":[...]}
    API-->>FE: data: [DONE]
```

## 6. 核心数据快照约束（接口视角）

- 下单接口 `POST /api/orders`：写入 `orders.receiver_info`（地址 JSON 快照）。
- 下单接口 `POST /api/orders`：写入 `order_items.buy_price`（价格快照）。
- 鉴权接口组：通过 `refresh_tokens + access_token_blocklist + token_version` 联动清退。

### 7.2 SSE 对话

```ts
import { fetchSSE } from '@/utils/request';

await fetchSSE({
  url: '/ai/chat/stream',
  body: { content: '帮我推荐三款适合通勤的轻薄本', context: { page_type: 'home', page_path: '/' } },
  onMessage: data => console.log('chunk', data),
  onDone: () => console.log('done'),
  onError: err => console.error(err),
});
```
